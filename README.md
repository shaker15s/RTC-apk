# مسار RTC للموبايل (Masar RTC Native Mobile) 📱✨

**تطبيق الهاتف النيتف الرسمي لمنظومة التدريب بمراكز رسالة (Resala Training Centers - RTC)**

تطبيق موبايل نيتف 100% مبني بـ React Native و Expo SDK 52 مع TypeScript، يعكس كل ميزة وشاشة في منصة مسار التدريبية (30 شاشة، 26 دالة RPC، هابتيكس، كاميرا QR نيتف، وتخزين مشفر).

---

## 🌟 الميزات الرئيسية للنسخة النيتف

- **عمارة نيتف نقية 100%:** أداء سلس 60/120 FPS وتجربة استخدام أصلية بالكامل دون أي WebViews.
- **عقد الـ RPC الـ 26 كاملاً:** تكامل تام ومباشر مع قاعدة بيانات Supabase عبر استدعاءات PostgreSQL RPC الآمنة.
- **ماسح الـ QR الذكي بكاميرا الهاتف:** تسجيل حضور المحاضرات في ثانية واحدة عبر مسح كود المدرب.
- **تخزين مشفر وآمن (Keychain / Keystore):** حفظ بيانات الجلسة والمفاتيح عبر التشفير المعتمد للهاتف.
- **استجابة لمسية ذكية (Haptic Engine):** اهتزازات تفاعلية مخصصة عند الضغط والنجاح والتحذير.
- **تذكيرات وإشعارات المحاضرات المجدولة:** تنبيهات ذكية قبل موعد المحاضرة لتذكير الطالب.
- **الوضع الليلي الاحترافي (OLED Dark Mode):** تصميم مريح للعين وموفر للبطارية.
- **حراس المسارات الأمنية (Route Guards):** عزل تام للصلاحيات بحسب دور المستخدم (طالب / متطوع / مشرف).
- **كاش ودعم العمل دون اتصال:** استعراض الدورات والبيانات المسجلة حتى عند انقطاع الإنترنت.

## 🚀 التشغيل والتطوير المحلي (Local Development)

### 1. المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث).
- تثبيت تطبيق **Expo Go** على هاتفك (أندرويد من Google Play أو iOS من App Store).

### 2. تثبيت الحزم
```bash
cd rtc_mobile
npm install
```

### 3. تشغيل خادم التطوير
```bash
npm start
# أو للتشغيل مع مسح الكاش:
npm run start:clear
```
- امسح رمز الـ QR الظاهر في التيرمينال عبر تطبيق **Expo Go** على هاتفك لتشغيل التطبيق فوراً مع التحديث المباشر (Hot Reloading).

## 📦 البناء والإنتاج وإصدار الحزم (Production Build & EAS)

معرف التطبيق الموحد: `org.resala.rtc.masar`

### 1. إعداد EAS CLI
```bash
npm install -g eas-cli
eas login
```

### 2. بناء ملف APK للتجربة المباشرة على أندرويد
```bash
eas build --platform android --profile preview
```

### 3. بناء ملف AAB لمتجر Google Play
```bash
eas build --platform android --profile production
```

### 4. بناء ملف IPA لمتجر Apple App Store
```bash
eas build --platform ios --profile production
```

## 🔒 حماية البيانات والأمان (Security Standards)

- **Zero-Trust Backend:** لا يمكن لأي مستخدم تجاوز الصلاحيات الممنوحة له بفضل RLS و `SECURITY DEFINER` في PostgreSQL.
- **Privacy Masking:** حجب الأرقام والأسماء الحساسة في السجلات العامة والشهادات الموثقة.
- **Hardware Encryption:** حفظ توكنات الجلسة داخل رقاقة الأمان بالهاتف (Hardware Security Module).
