# مسار RTC للموبايل (Masar RTC Native Mobile) 📱✨

**تطبيق الهاتف النيتف الرسمي لمنظومة التدريب بمراكز رسالة (Resala Training Centers - RTC)**

تطبيق موبايل نيتف 100% مبني بـ React Native 0.81 و Expo SDK 54 مع TypeScript، يعكس كل ميزة وشاشة في منصة مسار التدريبية (36 شاشة، 28 دالة RPC، هابتيكس، كاميرا QR نيتف، وتخزين مشفر).

> **الإصدار الحالي v100.1.0 (تحديث الجودة الشامل)** — إصلاحات QA موثقة في `docs/QA-REPORT.md`، وتتضمن:
> زر منح نقاط حقيقي متصل بالداتابيز، تسجيل أجهزة الإشعارات وتذكيرات المحاضرات، وضع أوفلاين فعلي عبر NetInfo، رموز QR حقيقية قابلة للمسح، إخفاء أرقام الطلاب، فحص الملفات المرفوعة، روابط المحاضرات الأونلاين، وحراس مسارات مشدّدة.
> ⚠️ **مطلوب خطوة داتابيز واحدة:** نفّذ `docs/sql/2026-08-15-quality-fixes.sql` لتفعيل منح النقاط واسترجاع الجلسات النشطة.

## 🌟 الميزات الرئيسية للنسخة النيتف

- **عمارة نيتف نقية 100%:** أداء سلس 60/120 FPS وتجربة استخدام أصلية بالكامل دون أي WebViews.
- **عقد الـ RPC الـ 26 كاملاً:** تكامل تام ومباشر مع قاعدة بيانات Supabase عبر استدعاءات PostgreSQL RPC الآمنة.
- **ماسح الـ QR الذكي بكاميرا الهاتف:** تسجيل حضور المحاضرات في ثانية واحدة عبر مسح كود QR حقيقي يظهر على شاشة المدرب.
- **تخزين مشفر وآمن (Keychain / Keystore):** حفظ بيانات الجلسة والمفاتيح عبر التشفير المعتمد للهاتف.
- **استجابة لمسية ذكية (Haptic Engine):** اهتزازات تفاعلية مخصصة عند الضغط والنجاح والتحذير.
- **تذكيرات وإشعارات المحاضرات المجدولة:** تسجيل جهازك للتنبيهات وتذكير قبل موعد المحاضرة عند الانضمام لمجموعة.
- **الوضع الليلي الاحترافي (OLED Dark Mode):** تصميم مريح للعين وموفر للبطارية من غير وميض عند الإقلاع.
- **حراس المسارات الأمنية (Route Guards):** عزل تام للصلاحيات بحسب دور المستخدم (طالب / متطوع / مشرف) على الشاشات والتبويبات.
- **وضع الأوفلاين الحقيقي:** كشف فعلي للشبكة عبر NetInfo مع شريط تنبيه وكاش للفروع والدورات.
- **سجل حضور تفصيلي للطالب:** كل محاضرة بحالتها (حاضر/متأخر/غائب/معذور) ونقاطها وتاريخها.
- **شهادات قابلة للمشاركة كصورة:** بطاقة شهادة معتمدة بتصميم رسمي + QR موثّق تُصدَّر كصورة PNG وتُشارك مباشرة.
- **تنقل نيتف حقيقي (React Navigation):** انتقالات أصلية، رجوع بالسحب على iOS، وروابط عميقة مثل `org.resala.rtc.masar://verify?serial=X`.
- **دعم ثنائي اللغة (العربية/English) كامل:** تبديل فوري من شاشة الحساب يغطي كل الشاشات (طالب/متطوع/مشرف) والمكونات عبر محرك i18n تفاعلي (719 مفتاحاً) مع سقوط تلقائي للعربية.
- **سجل حضور ذكي:** نسبة التزام حقيقية لكل دورة، أهلية الشهادة (75%) مع رسالة «تحتاج N محاضرات إضافية»، فلاتر بالحالة، وإجمالي نقاط الحضور.
- **شهادة PDF رسمية:** تصدير الشهادة كملف PDF (صورة الشهادة + السيريال + رابط التحقق) ومشاركتها مباشرة.

## 🚀 التشغيل والتطوير المحلي (Local Development)

### 1. المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث).
- تثبيت تطبيق **Expo Go** على هاتفك (أندرويد من Google Play أو iOS من App Store).

### 2. تثبيت الحزم
```bash
npm install
```

### 3. تشغيل خادم التطوير
```bash
npm start
# أو للتشغيل مع مسح الكاش:
npm run start:clear
```
- امسح رمز الـ QR الظاهر في التيرمينال عبر تطبيق **Expo Go** على هاتفك لتشغيل التطبيق فوراً مع التحديث المباشر (Hot Reloading).

## 📦 البناء والإنتاج وإصدار الحزم (Production Build & EAS)

معرف التطبيق الموحد: `org.resala.rtc.masar`

### 1. إعداد EAS CLI
```bash
npm install -g eas-cli
eas login
```

### 2. بناء ملف APK للتجربة المباشرة على أندرويد
```bash
eas build --platform android --profile preview
```

### 3. بناء ملف AAB لمتجر Google Play
```bash
eas build --platform android --profile production
```

### 4. بناء ملف IPA لمتجر Apple App Store
```bash
eas build --platform ios --profile production
```

## 🔄 آلية التحديث (Expo Go vs APK + OTA)

التحديث بيوصل بطريقتين مختلفتين تماماً حسب طريقة تشغيلك للتطبيق:

| الوضع | إزاي بيوصل التحديث |
|---|---|
| **Expo Go** (من بلاي ستور) | بس عبر السيرفر المحلي `npx expo start` — التعديلات بتوصل فورياً (Fast Refresh). **`eas update` مش بيأثر على Expo Go إطلاقاً.** |
| **APK حقيقي** (من `eas build`) | تحديثات OTA من فرع `preview` (القناة متظبطة في eas.json). التحديث بيتنزّل في الخلفية عند فتح التطبيق، ويتفعّل عند إعادة الفتح. |

**القواعد الذهبية:**
1. تعديل على شاشات/منطق (JS/TSX) → `npx eas-cli update --branch preview --message "..."` كفاية.
2. تعديل على `app.json` أو أي حاجة نيتف → مطلوب `eas build` جديد.
3. أي **رفع للإصدار** (`version`) → مطلوب build جديد مرة واحدة، لأن الـ OTA مربوط بالإصدار (`runtimeVersion: appVersion`) — النسخ القديمة مش هتقبل تحديثات الإصدار الجديد.

## 🔒 حماية البيانات والأمان (Security Standards)

- **Zero-Trust Backend:** لا يمكن لأي مستخدم تجاوز الصلاحيات الممنوحة له بفضل RLS و `SECURITY DEFINER` في PostgreSQL.
- **Privacy Masking:** حجب الأرقام والأسماء الحساسة في السجلات العامة والشهادات الموثقة.
- **Hardware Encryption:** حفظ توكنات الجلسة داخل رقاقة الأمان بالهاتف (Hardware Security Module).
